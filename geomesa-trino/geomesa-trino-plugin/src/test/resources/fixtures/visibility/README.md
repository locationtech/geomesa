These files are generated by `VisibilityMetadataTest` in `geomesa-fs-storage`.

`mixed.parquet` contains six rows with visibility `A`, `A&B`, `C|D`, `A`, empty,
and NULL. Its footer contains a version 1 normalized AND rollup and an unrestricted
OR rollup. `restricted.parquet` contains the first four rows, with a normalized
OR rollup that permits whole-file rejection. `positions.parquet` is an Iceberg position-delete file removing row
zero of `memory:///mixed.parquet`.

`spatial.parquet` contains the same six visibility values with GeoParquet point
geometry and bounding-box columns. It includes points outside, inside, and on the
boundary of the test query envelope to verify spatial and visibility filtering together.

Regenerate from the repository root:

```sh
mvn -pl geomesa-fs/geomesa-fs-storage -Dtest=VisibilityMetadataTest \
  -Dgeomesa.rollup.fixture=/tmp/visibility-rollup.parquet test
cp /tmp/visibility-rollup.parquet \
  geomesa-trino/geomesa-trino-plugin/src/test/resources/fixtures/visibility/mixed.parquet
cp /tmp/visibility-rollup.parquet.deletes \
  geomesa-trino/geomesa-trino-plugin/src/test/resources/fixtures/visibility/positions.parquet
cp /tmp/visibility-rollup.parquet.restricted \
  geomesa-trino/geomesa-trino-plugin/src/test/resources/fixtures/visibility/restricted.parquet
cp /tmp/visibility-rollup.parquet.spatial \
  geomesa-trino/geomesa-trino-plugin/src/test/resources/fixtures/visibility/spatial.parquet
```
